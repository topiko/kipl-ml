## Reproduce Laserbeak

Note: you need to add the (Laserbeak)[https://github.com/notem/Laserbeak-WF-Classifier/tree/main] repo into your `$PYTHONPATH`. 

To achieve this mod you virtualenv activate (or run `conda-develop .` in the root of Laserbeak) by adding:

`export PYTHONPATH="$PYTHONPATH:/path/to/Laserbeak-WF-Classifier"`

You'll also need (pytorch-image-models)[https://github.com/huggingface/pytorch-image-models/tree/a6e8598aaf90261402f3e9e9a3f12eac81356e9d] installed.
